# zeludas.github.io

Personal website of [Aleksandr Zheludkov](https://zeludas.github.io/), an IT & AI consultant based in Lisbon and working internationally.

## Technical approach

- Static, dependency-free HTML and CSS
- No executable JavaScript, analytics, cookies, forms, or third-party resources
- Responsive and accessible layout
- Structured metadata, Open Graph preview, sitemap, and robots directives
- Direct deployment from the `main` branch through GitHub Pages

## Local preview

Serve the repository root with any static HTTP server, then open the local URL in a browser. No build step is required.

## Deployment

GitHub Pages publishes the repository root from the `main` branch to [zeludas.github.io](https://zeludas.github.io/). The `.nojekyll` file keeps the deployment path intentionally simple.
